ADMIN PORTAL:  https://liverpool-club.netlify.app/admin/

HOW TO GET ADMIN ACCESS:
  1. Register on the website with your own email (Google Sign-In)
  2. Contact the developer — he will promote your account to Admin
     or Head Admin from the Members panel
  3. Once promoted, go to https://liverpool-club.netlify.app/admin/ and you're in

  ℹ️  You do NOT get a separate admin password.
      You log in with the same account you registered with.
      The developer controls who gets admin access.

CONTENT MANAGEMENT
  • Add / edit / delete → Projects, Events, Moments, Resources
  • Manage Leadership profiles shown on site
  • Update club Settings (name, schedule, lab room, contact)

MEMBER MANAGEMENT
  • View all registered members + their profile & section
  • Promote member → Admin
  • Promote Admin → Head Admin
  • Demote Head Admin → Admin
  • (Master admin emails can never be demoted)

STUDENT SUBMISSIONS
  • Review submitted Project Ideas
  • Accept idea → notifies student automatically
  • Reject idea → notifies student automatically
  • Convert idea directly into a live Club Project
  • Approve / hide Testimonials (Voices)

COMMUNICATIONS
  • Send global broadcast notification to ALL members
  • Send personal notification to a single member
  • Read & reply to student messages (inbox)
  • Delete old broadcast notifications
